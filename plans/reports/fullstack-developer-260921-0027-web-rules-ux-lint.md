## Deliverable 1 — `/rules`

Single page, seven anchored sections (chain, clock, dead end, elimination, scoring, room
codes, reconnect), a pill nav at the top, all copy in `vi.js`. Scoring section states the
actual formula and constants read from `server/internal/game/engine.go` (`pointsFor`,
`speedPoints`, `rarityPoints`, read-only): base 10, +2/word up to the first 15, +5/syllable
past the 2-syllable minimum, up to +10 for speed (full instantly, linear to 0 at the buzzer),
up to +15 for rarity (−3 per doubling of the syllable's option count), capped at 100/word. The
constants live in a small `SCORING` object in the route with a comment naming the source
functions, since the page is static and these are compile-time constants, not something the
wire sends.

Linked from the landing page (own line under the two big actions, not a third button) and from
`GameBoard`'s `.top` row and `Lobby`'s `.top` row via a shared `.rules-link` class in
`app.css`, so it appears in both the bot game, the online game, and the lobby without three
separate style blocks.

## Deliverable 2 — UX leftovers (C1)

**2a — hoist the chat toggle.** Followed the 2026-09-10 report's own recommendation (option
a, not the DOM-reorder option it called "wrong on a phone"): a pill button now sits in

## Deliverable 3 — ESLint + JSDoc (F1)

Flat config (`eslint.config.js`): `@eslint/js` recommended, `eslint-plugin-svelte`'s
`flat/recommended`, `eslint-plugin-jsdoc`'s `flat/recommended-typescript-flavor` (fits a
JS+JSDoc project better than plain `recommended`: it turns off `no-undefined-types`, which
otherwise misreads this codebase's TS-flavoured JSDoc generics). `globals.browser` for
`src/`, `globals.node` for `*.config.js`/`tests/**`/`e2e/**`. `src/lib/proto/**` is excluded
(generated, not ours to fix).

Two narrow, justified rule overrides, both with an inline comment in `eslint.config.js`:

- `svelte/no-navigation-without-resolve`: off. This app has no base path (adapter-static,
  served from `/` by the Go binary) and several of its own links append a query string at the
  call site (`/play?difficulty=`, `/online?code=`) — a shape the rule's `resolve()` cannot
  express (confirmed via the plugin's own open issues on search-param hrefs). Adopting
  `resolve()` would work around a limitation for a base path this app will never have.
- `jsdoc/require-jsdoc`, `require-param`, `require-param-description`, `require-param-type`,
  `require-property*`, `require-returns*`: off. This codebase types function/component
  inputs with one `@type {{ ... }}` object-shape block (every component's props, e.g.
  `GameBoard.svelte`) rather than per-parameter `@param name description` lines, which is
  what these rules expect; turning them on flagged ~400 warnings that were the codebase's
  actual documentation style, not missing documentation. Left everything else on, including
  `check-tag-names`, `check-param-names`, `check-types`, and `reject-any-type`.

Ran it, fixed what was real:
- `svelte/require-each-key` (4 sites) — added keys: chain entries by `word` (unique, no word
  is ever reused), a word's senses by `gloss`, chat messages by `playerId + atMs`, suggestion
  words by the word itself.
- `svelte/prefer-svelte-reactivity` (1 site) — `game.svelte.js`'s `kept` is a static lookup
  `Set`, built once, never mutated, never read by a template; a scoped disable with a comment
  rather than converting it to `SvelteSet` for reactivity it will never use.
- `jsdoc/reject-any-type`, 3 of 32 sites — the three that were plainly a timer handle
  (`GameBoard.svelte`, `Lobby.svelte`, `RoomCodePanel.svelte`'s `armTimer`/`clearTimer`) got
  `ReturnType<typeof setTimeout>`; verified with `npm run check` (still 0 errors).
- `jsdoc/tag-lines` (blank line before a tag block) — ran `eslint --fix`; purely
  whitespace-in-comments, touched most files under `src/`, `tests/`, and `e2e/`.

`npm install --save-dev` with caret ranges (`eslint@^10.11.0`, `@eslint/js@^10.0.1`,
`eslint-plugin-svelte@^3.23.0`, `eslint-plugin-jsdoc@^64.5.4`, `globals@^17.12.0`), all
compatible with the pinned `eslint`/`svelte`/node peer ranges. `npm approve-scripts esbuild`
